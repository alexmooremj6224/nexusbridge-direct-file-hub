## What Is NexusBridge?

NexusBridge enables encrypted, peer-to-peer file exchange without routing transferred data through an intermediary storage service. It uses NAT traversal and hole-punching techniques to help establish direct connections between participating devices.

The project provides a lightweight sharing experience across platforms, combining adaptive streaming with multi-protocol connectivity. Its AI integration also supports modern transfer workflows that benefit from flexible behavior and limited overhead.

## Transfer Workflow

NexusBridge follows a sender-and-recipient model for direct sharing:

1. Open the application on both devices.
2. Create a sharing session or join an existing one.
3. Allow peer-to-peer traversal to establish the connection.
4. Select the files that should be encrypted and transferred.
5. Follow the transfer status while the data moves between the endpoints.

A typical session looks like this:

- Launch NexusBridge
- Pair with the remote peer
- Choose one or more files
- Start the transfer
- Wait for the completion confirmation

## Frequently Asked Questions

**How can I update NexusBridge?**  
Download the newest published build from the project release or download page.

**Why is the peer connection not being created?**  
Review the network conditions, confirm that the other peer is available, and inspect NAT traversal and protocol-selection settings.

**Where does NexusBridge save configuration changes?**  
Depending on how the application is run, settings are managed either inside the app or through local project configuration.

**Does NexusBridge work across platforms?**  
Yes. NexusBridge is identified as a cross-platform application.

**How should I respond to a failed transfer?**  
Start the session again, make sure both peers are online, and check that the selected connection mode is suitable for the current network environment.
